# RiverPools — план трекинга

Инструменты: Яндекс.Метрика (id: **уточнить у заказчика** — 109864768 или
109286676), Roistat call-tracking (подмена номера). Событийный слой уже внедрён
в код и включается одной строкой: `src/data/config.js → metrikaId`.

Пока id не задан, события копятся в `window.__events` (удобно для QA).

## Ключевая конверсия

| Конверсия | Событие/цель | Где срабатывает |
|---|---|---|
| Заявка | `formsent` (reachGoal) + `form_submitted` | успешный сабмит квиза или финальной формы |

На `formsent` настраиваются цели Директа. `form_submitted{form}` различает
источник: `quiz-form` или `final-form`.

## События (object_action, snake_case)

| Событие | Параметры | Триггер | Какое решение информирует |
|---|---|---|---|
| `form_submitted` | `form` (quiz-form / final-form) | успешная отправка | какой механизм заявки работает лучше |
| `quiz_step_completed` | `step` (location/size/budget), `value` | клик по варианту шага | где отваливаются в квизе; спрос по размерам/бюджетам |
| `quiz_result_shown` | `model` | показ рекомендации | какие модели рекомендует квиз vs что заказывают |
| `model_modal_opened` | `model` | открытие карточки модели | интерес к моделям → приоритеты каталога/рекламы |
| `process_stage_reached` | `stage` (STAGE_01…08) | первая прокрутка до фазы (раз/сессию) | глубина вовлечения в сцену; где бросают скролл |
| `phone_clicked` | `location` (pill-nav / sticky-cta / nav-drawer / site-footer) | клик по tel: | вклад звонков по зонам; сверка с Roistat |
| `cta_clicked` | `text`, `href` | клик по любой кнопке-CTA | какие CTA двигают к заявке |

## Включение Метрики (прод)

1. Выбрать id счётчика (заказчик), вписать в `src/data/config.js → metrikaId`.
2. Добавить сниппет Метрики в `<head>` index.html (webvisor: true, clickmap: true).
3. В Метрике создать цели: `formsent` (главная) + JavaScript-события из таблицы.
4. Roistat: вставить сниппет подмены номера; события `phone_clicked` сверять
   с коллтрекингом (двойной учёт звонков не суммировать).
5. Проверка: открыть сайт с `?qa=1`, выполнить заявку на dev-заглушке,
   убедиться, что `window.__events` пуст (события ушли в ym), цели видны
   в отчёте «Конверсии» в реальном времени.

## UTM-конвенции

`utm_source` (yandex / vk / 2gis), `utm_medium` (cpc / maps / referral),
`utm_campaign` (pool_summer_2026), `utm_content` (объявление/креатив),
всё в lower_snake_case. Формы автоматически прикладывают `page` (URL со
всеми utm) к каждой заявке — разметка попадает в CRM без доп. работы.

## Приватность

PII (имя, телефон) в события не передаётся — только в форму на бэкенд.
Согласие 152-ФЗ собирается чекбоксом в обеих формах.
