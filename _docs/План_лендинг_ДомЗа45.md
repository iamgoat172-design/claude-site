# План: лендинг конкретного дома из СИП + калькулятор «под ключ» («Дом за 45»)

## Context (зачем)
Клиент — **«Дом за 45»** (domza45.ru; проектировщик/подрядчик ООО «Династия», Москва; экосистема Вологодского Зодчества). Нужен **сайт-лендинг под ОДИН конкретный дом** из СИП-панелей с **интерактивным расчётом цены «под ключ»**, структурно по референсу **cherchill.forestvologda.com** (лендинг одного дома). Инфа о компании — lp.domza45.ru / lp2.domza45.ru. Итог сессии — этот план; продакшн делегируется **frontend-engineer**.

Ключевой инсайт разведки: cherchill сознательно даёт ОДНУ фикс-цену «под ключ» + арифметическую разбивку по этапам («выбирать ничего не нужно»). Мы совмещаем это с расчётом-конструктором и УТП domza45 «за 45 дней / фикс-цена без доплат».

## Решения Алексея (13.07.2026)
1. **Механика цены — гибрид:** фикс «под ключ» одним числом + прозрачная разбивка по 5 этапам сметы + рабочий ипотечный калькулятор. Без «собери сам».
2. **Hero-цена — хук «от тёплого контура»:** «от 3 320 000 ₽» (тёплый контур), полный «под ключ» раскрывается ниже. Честная лестница комплектаций снимает эффект bait-and-switch.
3. **Стек — статик self-contained:** HTML+CSS+JS+ассеты, zip → Netlify Drop / любой хостинг (наш проверенный путь, как сайт Династии, см. [[zip-static-site-for-hosting]]).

## Данные дома (контент)
Одноэтажный дом из СИП-панелей, современный, графитовый фасад, в лесу.
- Фасад: сайдинг Grand Line Акрил графит; кровля: металлочерепица Grand Line Satin графит.
- Окна: 9× Rehau GRAZIO 70мм, двухкамерные, ламинация, 50% открывания; панорамное остекление.
- Фундамент: 35 забивных ж/б свай 150×150 L=3000.
- Площади: пятно/перекрытие/стены ≈ 84 м²; кровля 135 м²; терраса ДПК ≈ 20,6 м².
- Инженерка: газовый котёл + бойлер, скважина + кессон Лотос, ЛОС Аэробокс А-410-8, приточная вентиляция.
- Отделка: потолок — вагонка ангарская сосна; пол — керамогранит + ламинат; стены — ГКЛ/обои, мокрые зоны — плитка.
- Проектировщик/подрядчик: ООО «Династия», Москва (печать в раб. проекте).

## Структура секций (адаптация cherchill → наш СИП-дом + «45 дней»)
1. **Хедер** — лого «Дом за 45», якорь-меню (Цена · Что входит · Комплектации · Ипотека · Галерея · Гарантии · FAQ), тел +7 (495) 128-15-41, Telegram, «Заказать звонок». Sticky-CTA на мобайле.
2. **Hero** — гл. рендер 4K; «Одноэтажный дом из СИП · 84 м² · за 45 дней»; спеки (84 м² | спальни | терраса 20 м² | панорамные окна); хук-цена «от 3 320 000 ₽ (тёплый контур)»; CTA «Рассчитать под ключ» + «Скачать смету PDF».
3. **VizStrip-галерея** — полоса ракурсов/сезонов (реальные фото на всю ширину), рвёт стену текста.
4. **Цена (#price)** — big-number «под ключ 10 221 638 ₽ — зафиксировано в договоре»; анти-доплатный фрейминг «Рынок: от X → доплаты → Y+ / У нас: фикс»; дата актуальности (факт).
5. **Что входит / Комплектации (#included)** — лестница комплектаций + разбивка «под ключа» на 5 этапов (карточки с суммами, складываются в 10,2 млн). «Всё в одной фиксированной цене».
6. **Ипотека (#mortgage)** — рабочий калькулятор: стоимость, первый взнос (слайдер 15–80%), срок (5–30 лет), ставка от 6% → платёж/мес, сумма кредита, переплата (живой пересчёт); банки Сбер/ВТБ/Альфа/Дом.РФ; CTA предодобрение.
7. **Характеристики/планировка (#plans)** — ТТХ дома (СИП 174/224 мм, окна Rehau, кровля, отопление газ, ЛОС и т.д.). ⚠️ Чертежа плана в вводных НЕТ — либо запросить у клиента, либо блок «характеристики» без плана (см. Открытые данные).
8. **Интерьеры** — 3D-рендеры (гостиная/спальня/ванная/прихожая/вечер) + «реальные интерьеры» из медиа-кита.
9. **Технология СИП / за 45 дней** — таймлайн 45 дней (6 фаз) + преимущества СИП (тепло/скорость/цена).
10. **Кастомизация** — «Изменить планировку? Архитектор бесплатно адаптирует» → CTA к архитектору.
11. **Метрики/соцдоказательство** — реальные из domza45 (180+ семей, 30+ проектов, гарантия 10 лет, 45 дней). Только факты.
12. **Построенные дома + отзывы** — сезоны (лето/осень/зима) из медиа-кита + честные кейсы.
13. **Гарантии/договор** — гарантия 10 лет, фикс-цена в договоре, поэтапная оплата.
14. **FAQ (#faq)** — аккордеон возражений (изменения проекта, цена на своём участке, ипотека, сроки/штрафы, что покрывает гарантия, что докупать). FAQ **перед** финальной формой ([[honest-brand-landing-conversion]]).
15. **Финальный CTA** — «Выберите формат» (смета PDF / расчёт под ключ / звонок архитектора / экскурсия) + форма (Имя/тел/email + согласие) + модалка «Спасибо, перезвоним».
16. **Футер** — лого, тел, Telegram, адрес Москва Дмитровское ш. 81 пом. 45/1, © ДОМ45 2026, юрлицо (см. Открытые данные).

## Сохранение материалов (перед стартом продакшна)
Собрать все вводные + план в проектную папку `C:\Users\User\Desktop\Проекты\Дом за 45 — лендинг\` (правило «рабочее не на рабочем столе» — [[desktop-cleanup-policy]]). **Каждый архив ≤ 30 МБ** (требование Алексея):
- `План_лендинг_ДомЗа45.md` — копия этого плана.
- `Ссылки.md` — 3 ссылки (lp.domza45.ru, lp2.domza45.ru, cherchill.forestvologda.com) + контекст.
- `Досье_3_сайта.md` — досье разведки по 3 сайтам (структура cherchill + инфа о компании).
- `Смета ЛП_(346АПП).pdf` (0,6 МБ) и `РАБОЧИЙ ПРОЕКТ.pdf` (5,7 МБ) — копии.
- `media/` — медиа-кит, **пережатый в WebP** (исходно 24 PNG/JPG ≈ 167 МБ → WebP q≈82, прогноз ≈ 15–25 МБ) → архив `Dom_SIP_media_web.zip` ≤ 30 МБ; если >30 МБ — разбить на части ≤ 30 МБ. Исходный 167 МБ zip остаётся в Downloads, тяжёлый архив НЕ храним.
Сжатие/архивацию/копирование выполняет general-purpose-агент (руки), Python/Pillow + `shutil.make_archive` ([[zip-static-site-for-hosting]]).
