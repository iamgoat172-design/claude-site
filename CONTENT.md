# Как подставить реальный контент (когда придут архивы)

Сейчас на сайте **заглушки**. Весь редактируемый контент — в одном файле:
**`src/lib/content.ts`**. Ниже — что и куда вставлять из архивов с проектами,
ценами и т.д.

## 1. Проекты (`projects`)

Каждый проект — объект:

```ts
{
  id: "nordic",          // латиницей, без пробелов (используется и как имя файла фото)
  title: "Nordic",       // название проекта
  tech: "Газобетон",     // материал — должен совпадать с фильтром (см. ниже)
  area: "164 м²",
  floors: "1 этаж",
  term: "6 мес.",
  price: "от 7,9 млн ₽",
  image: img.gazobeton,  // заменить на "/projects/nordic.jpg" (см. п.4)
  alt: "Краткое описание фото",
}
```

Значения `tech` должны совпадать со списком фильтров в `Projects.tsx`
(`Все, Газобетон, Кирпич, Тёплая керамика, Клееный брус, Фахверк`).
Если в архивах будут другие материалы — поправлю и фильтр.

## 2. Цены и технологии (`technologies`)

Блок «Технологии» — описания и `priceFrom` (цена за м²). Заменяется так же.

## 3. Тексты компании (`company`, `stats`, `guarantees`, `advantages`, `stages`, `reviews`, `faqs`)

- `company` — телефон, e-mail, адрес, мессенджеры, часы работы.
- `stats` — цифры (лет на рынке, построено домов и т.д.).
- `reviews`, `faqs` — реальные отзывы и вопросы из архивов.

## 4. Фотографии

Положить файлы в **`public/projects/`** (имя = `id` проекта, напр. `nordic.jpg`),
затем в `content.ts` указать путь:

```ts
image: "/projects/nordic.jpg",
```

Локальные фото предпочтительнее: сейчас изображения временно ссылаются на
внешний CDN (сгенерированные визуализации).
