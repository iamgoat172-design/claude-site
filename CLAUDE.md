# RiverPools — правила работы в этом репозитории

## Правило: HTML после каждой работы

После КАЖДОГО рабочего пасса (любые изменения кода/контента сайта) — собрать
самодостаточный одностраничный HTML и отправить его пользователю файлом
(SendUserFile, display: render), вместе с ключевыми скриншотами, если менялся визуал:

```bash
node scripts/build-single.mjs   # соберёт riverpools.html в корне scratchpad/dist-single
```

Перед отправкой — smoke-тест: открыть файл через `file://` в Chromium
(/opt/pw-browsers/*/chrome-linux/chrome), убедиться, что консоль чистая,
сцена стартует и карточки каталога рендерятся.
