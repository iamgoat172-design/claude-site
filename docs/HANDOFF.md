## Проект
Премиум-лендинг (без слова «премиум»!) под рекламу для **«Вологодское Зодчество»** — дома от 250 м² из **клееного бруса** и **тёплой керамики**. Эстетика: **Spatial UI / Liquid Glass**, тёмный кинематографичный холст, фото-как-материал, крупная типографика.

### Стек и сборка
- **Astro 5 + Tailwind v4** (`@tailwindcss/vite`). Интерактив — ванильный JS в `.astro`.
- Обычная сборка: `npm run build`. Дев: `npm run dev`.
- **Автономный файл** (двойной клик, демо клиенту): `SINGLEFILE=1 npm run build` затем `node scripts/inline-local-images.mjs` (вшивает локальные `/images/*` как data-URI). Плагин `vite-plugin-singlefile`.
- Хостинг: есть `.github/workflows/deploy.yml` (GitHub Pages, нужно включить Source=GitHub Actions в Settings→Pages) ИЛИ Netlify Drop папки `dist`.

### Дизайн-система — `src/styles/global.css`
- Палитра: `--color-ink #14161B`, `--ink-2 #1E2128`, `--paper #F7F7F5`, `--fog #ECEBE7`, `--muted #6B6F78`, `--on-ink #F4F3F0`, `--accent #B0885A` (дрифтвуд, дозированно), `--accent-soft #C8A578`.
- Шрифты: **Unbounded** (дисплей) + **Manrope** (UI), обе с кириллицей (Google Fonts).
- Утилиты: `.glass`, `.glass-light`, `.hairline-top`, `.grain`, `.vignette`, `.eyebrow`, `.display-xl/.display-lg`, `.tnum`, `.reveal/.rise` (появление), `.kenburns`. Везде учитывается `prefers-reduced-motion`.

### Higgsfield (hig MCP) — генерация изображений
- Воркспейс выбран; модель **`nano_banana_pro`** (2 кр/2k, 4 кр/4k). Генерили hero, экстерьеры, интерьеры.

## ⛔ ОТКРЫТЫЙ ВОПРОС — листинг проектов (на нём и остановились)
Клиент хочет **инновационный, премиальный, ИНТЕРАКТИВНЫЙ** листинг, «с которым хочется взаимодействовать». Уже отвергнуты ВСЕ собранные варианты (есть как демо-страницы и `variant`-проп в `Catalog.astro`):
- `list` (боковой список, в проде index) — «колхозно»
- `showcase` (кинолента) — ок, но не то
- `coverflow` (3D-карусель) — «колхозно»
- `spread` (журнальный разворот) — отвергнут
- `collection` (chrome-less Ken Burns + типографский индекс) — «всё равно плохо»
- `table` (стол архитектора: drag/zoom/фокус) — «прикольно, но не формат»

Демо-страницы: `/catalog-variant`, `/catalog-coverflow`, `/catalog-spread`, `/catalog-collection`, `/catalog-table`.

**Следующий шаг:** придумать/собрать НОВУЮ механику листинга, которая попадёт в «премиум + интерактив». Предлагал меню механик (день↔ночь ползунок, сравнение-шторка материалов, свайп-колода, 3D-облёт) — клиент пока не выбрал. Нужен его референс/жест ИЛИ более смелая идея. Всё остальное (hero, секции, оба поп-апа, формы, данные) — в рабочем состоянии.
