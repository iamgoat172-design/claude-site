# СК «Династия» — сайт строительной компании

Инновационный одностраничный сайт для строительной компании «Династия»
(Санкт-Петербург и Ленинградская область). Цель — «легко и дорого»: лёгкий,
воздушный интерфейс на белом фоне, глубокие петролевые акценты и тёплая латунь
как знак премиальности. Контент перенесён с лендинга `lp.sk-dinastiya.com`
с более современной структурой и подачей.

## Стек

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4** — дизайн-токены в OKLCH (`src/app/globals.css`)
- **Motion** (`motion/react`) — хореография появления, параллакс, интерактив
- **Lenis** — плавный скролл
- Шрифты: **Spectral** (дисплейный, заголовки) + **Onest** (текст), кириллица

## Структура

| Раздел | Компонент |
|---|---|
| Шапка (sticky, прозрачная → плотная) | `Header` |
| Hero с параллаксом | `Hero` |
| Статистика (анимированные счётчики) | `Stats` |
| Технологии (интерактивный выбор) | `Technologies` |
| Проекты (фильтр по материалу) | `Projects` |
| Этапы работ (таймлайн) | `Process` |
| Преимущества | `Advantages` |
| Гарантия 25 лет | `Guarantees` |
| Отзывы | `Reviews` |
| FAQ (аккордеон) | `Faq` |
| Контакты + форма заявки | `Contact` |
| Подвал | `Footer` |

Весь контент собран в `src/lib/content.ts`.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
```

## Что заменить на реальные данные

- **Проекты** в `src/lib/content.ts` — сейчас демонстрационные (названия, площади,
  цены). Подставьте фактические проекты, описания и цены с исходного сайта.
- **Изображения** (`img` в `content.ts`) — сгенерированы (CDN). Для production
  лучше скачать в `public/` и раздавать локально, либо заменить на реальные фото
  объектов.
- **Форма заявки** (`Contact.tsx`) — сейчас демо. Подключите CRM / e-mail /
  Telegram-бот в обработчике `submit`.
- **Соцсети/мессенджеры** — проверьте ссылки WhatsApp / Telegram.
