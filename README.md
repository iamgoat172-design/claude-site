# Вологодское Зодчество — премиум-лендинг

Отдельная посадочная под рекламу премиум-линейки: дома от 250 м² из **клееного
бруса** и **тёплой керамики (поротерм)**. Эстетика — **Spatial UI / Liquid Glass**:
футуризм в интерфейсе (стекло, глубина, свет, движение), тепло и «дорого-спокойно»
в крупной архитектурной фотографии.

## Стек

- **Astro 5** + **Tailwind CSS v4** (`@tailwindcss/vite`)
- Интерактив — лёгкие острова на ванильном JS (табы материалов, форма)
- Адаптив: 375 / 768 / 1024 / 1440

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/
npm run preview
```

## Дизайн-система

Источник правды по токенам — `src/styles/global.css` (`@theme` + `:root`).

| Токен | Значение | Назначение |
|-------|----------|------------|
| `--color-ink` | `#14161B` | графит-«ночь» |
| `--color-ink-2` | `#1E2128` | глубина/поверхности |
| `--color-paper` | `#F7F7F5` | архитектурный белый |
| `--color-fog` | `#ECEBE7` | камень/туман |
| `--color-muted` | `#6B6F78` | приглушённый текст |
| `--color-on-ink` | `#F4F3F0` | текст на тёмном |
| `--color-accent` | `#B0885A` | тёплый дрифтвуд (дозированно) |

Шрифты: **Unbounded** (дисплей) + **Manrope** (UI) — обе с кириллицей.
Стекло: `.glass` (blur 32px / saturate 170% / radius 24px / тень + хайрлайн).

## Изображения

> подключены по URL с CDN — для превью на согласование. Адреса собраны в

**Перед продакшеном — локализовать:**
1. Скачать кадры (или заменить реальными фото объектов).
2. Положить оптимизированные `AVIF/WebP` в `public/images/projects/`.
3. Заменить URL в `src/data/projects.ts` на локальные пути (`/images/...`).
4. Hero отдавать в нескольких размерах (`srcset`); всё ниже первого экрана — `loading="lazy"` (уже размечено).

> Примечание: автоматическую загрузку кадров в репозиторий блокирует
> egress-политика окружения (CDN-хост не в allowlist). Чтобы я мог скачать и
> оптимизировать их сам — добавьте хост в allowlist сети, либо пришлите фото.

## Форма заявки → CRM

Форма (клиент) валидирует поля и шлёт `POST` JSON
`{ name, phone, material, area, consent }` на **`PUBLIC_LEAD_ENDPOINT`**
(`.env`, по умолчанию `/api/lead`). Этот адрес — ваш серверный прокси
(serverless-функция), который добавляет секрет и пересылает лид в CRM
(напр. Bitrix24 `crm.lead.add`). Если переменная пуста — форма работает в
**демо-режиме** (валидация + успех, без реальной отправки), payload пишется
в консоль.

Подключение прокси — на вашей стороне. Реквизиты CRM держим в `.env`
(шаблон — `.env.example`); секреты в репозиторий не коммитим.
