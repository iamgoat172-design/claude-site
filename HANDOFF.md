## 2. Арт-направление (ЖЁСТКОЕ — не отступать)

Эстетика: **футуристично, но элегантно и современно.**
Принцип: **футуризм — в интерфейсе** (стекло, глубина, свет, движение,
типографика); **тепло и «дорого-спокойно» — в крупных фотографиях** домов,
природы, интерьеров. Фото — главный материал.

Стиль = **Spatial UI / Liquid Glass**: парящие frosted-glass панели поверх
крупной архитектурной фотографии, мягкая глубина, параллакс, плавные кривые
400–600 мс, focus-scale 1.02.

### ❌ Запрещено (прошлый заход был провальным — НЕ повторять)
- Холодный sci-fi, неон, киберпанк, тёмно-фиолетовые «AI-градиенты».
- Золото + чёрный.
- Editorial-монография.
- Серые плейсхолдеры.
- Teal/бирюза (это дефолт скилла — **отклонён**).
- Шрифты без кириллицы: Space Grotesk, Sora, Cinzel, Josefin Sans — **нельзя**.

### ✅ Палитра (источник правды — `src/styles/global.css`)
| Токен | HEX | Назначение |
|---|---|---|
| `--color-ink` | `#14161B` | графит-«ночь» |
| `--color-ink-2` | `#1E2128` | глубина/поверхности |
| `--color-paper` | `#F7F7F5` | архитектурный белый |
| `--color-fog` | `#ECEBE7` | камень/туман |
| `--color-muted` | `#6B6F78` | приглушённый текст |
| `--color-on-ink` | `#F4F3F0` | текст на тёмном |
| `--color-accent` | `#B0885A` | тёплый дрифтвуд/дерево — **дозированно** (линия, активное состояние, свечение; НЕ заливать блоки) |

Стекло: `glass-dark rgba(255,255,255,.07)`, `glass-light rgba(255,255,255,.60)`,
хайрлайн `rgba(255,255,255,.16)`, обязательный **scrim** под текстом на фото
(контраст ≥ 4.5:1).

### ✅ Типографика (обе с кириллицей — проверено)
- **Дисплей/Hero:** Unbounded (400–600, крупно, трекинг ~-0.02em).
  Если ощущается «слишком техно» — Manrope 600 крупным.
- **UI/текст:** Manrope (300–700).

### Рецепт стеклянной панели (един по сайту)
```css
background: var(--glass-dark);
backdrop-filter: blur(32px) saturate(170%);   /* диапазон 28–40px */
border: 1px solid rgba(255,255,255,.16);
border-radius: 24px;
box-shadow: 0 16px 48px rgba(0,0,0,.28);
```
+ ограничивать число одновременно блюрящихся слоёв (перформанс).

## 3. Ключевой элемент — ТАБЫ МАТЕРИАЛОВ

Каталог — это **не две простыни подряд**, а один блок с переключателем:
`[ Клееный брус ] [ Тёплая керамика ]`.
- Таб = frosted-glass пилюля; активный — подсветка `--accent` + «liquid»
  стеклянный индикатор, перетекающий между табами (300–400 мс, через
  `transform`, не layout).
- Переключение → сетка проектов плавно сменяется (fade/slide, без перезагрузки,
  без CLS).
- Карточки: крупное фото, код ВЗ, площадь, этажи, цена/«по запросу»;
  hover → лёгкий подъём + парение стекла.
- Доступность: `role=tablist/tab`, `aria-selected`, клавиатура ←/→/Home/End.
- Это **центр страницы** — должно быть визуально вкусным.

## 4. Структура секций (порядок в `src/pages/index.astro`)

Header → Hero → TrustStrip (доверие) → **Catalog (табы)** → Included
(что входит) → Stages (этапы) → Pricing (стоимость + ипотека) → Built
(построенные дома) → Reviews (отзывы) → DesignBureau (авторское
проектирование 300+ м²) → Geography (МО и ЛО) → LeadForm → Footer.

Форма заявки: имя, **телефон (обязателен)**, материал-селект, площадь,
согласие. Доп. правило из прошлой сессии: **в формах телефон всегда
обязателен + Telegram-ник по желанию.** Общий поп-ап проекта + форма
переиспользуются во всех вариантах каталога.

- `catalog-collection.astro` — chrome-less кинематографичный.
- `catalog-table.astro` — «стол архитектора».
- `catalog-variant.astro` — showcase-вариант.
> Если нужно выбрать один — спроси заказчика, какой ставим на главную.

## 6. РЕШЕНИЯ заказчика (актуальные, перекрывают старые вопросы)

1. **Фото:** реальных пока нет. Оставляем **заглушки**, наполним после.
   Если по ходу нужны визуалы — **генерировать в Higgsfield** (MCP-сервер
   `hig`: `generate_image` и т.п.). Сейчас в макете стоят сгенерированные
   кадры с CDN (`IMG_BASE` в `src/data/projects.ts`) + локальные WebP для двух
   реальных проектов в `public/images/projects/`.
2. **Референсы:** НЕ нужны — заказчик хочет **уникальный продукт.**
   Не равняться на чужие сайты.
3. **CRM:** заказчик подключит **сам.** Наша часть — оставить `.env`
   (`.env.example`) + клиентскую отправку на `PUBLIC_LEAD_ENDPOINT`
   (демо-режим, если пусто). Секреты в репозиторий не коммитим.

**Реальные проекты, уже внесённые с данными/планировками:**
- `ВЗ-472 «Поместье Ели»` (брус, 628 м²) — фото + планы локально.
